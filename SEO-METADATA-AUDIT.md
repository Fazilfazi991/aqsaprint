# SEO Metadata Audit

Date: 2026-07-12

## Site Architecture

- Framework: Static HTML/CSS/JavaScript website.
- Hosting/routing: Vercel static deployment with `cleanUrls: true`; API endpoints under `/api/*.js` use Vercel serverless functions.
- Rendering method: Metadata is rendered directly in initial static HTML.
- Metadata implementation: Reusable Node script at `scripts/seo-metadata-pass.cjs` updates titles, descriptions, canonicals, robots, Open Graph, Twitter and JSON-LD.
- Canonical domain: `https://www.aqsaprint.com`.
- Sitemap: Static `sitemap.xml` generated from public HTML routes.
- Robots: Static `robots.txt` allows public crawl and excludes admin/API/login/thank-you.
- English/Arabic handling: Main document language is English. Homepage includes an Arabic slide, but no complete Arabic URL set exists, so hreflang was not added.
